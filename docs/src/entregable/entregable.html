02Informe técnico

Nombre y logotipo

monOS (de mono + OS). El logotipo es un mono programando en una laptop; la identidad combina monos, galaxias y tecnología con una paleta fija (azul #0C6BFA, violeta #7C3AED, fondo #0B0D12) aplicada a todo el sistema: GRUB, pantalla de carga, login, escritorio, terminal y editores.

Distribución base

Arch Linux (modelo rolling release: software siempre actualizado y acceso al AUR). Kernel linux 7.2 con linux-lts como respaldo, escritorio KDE Plasma 6.7.5 sobre Wayland, sistema de archivos Btrfs con snapshots automáticos (Snapper) y la imagen ISO construida con archiso, la herramienta oficial de Arch.

Paquetes clave instalados

  • Escritorio: KDE Plasma 6, SDDM, Dolphin, Discover + Flatpak, temas propios (Klassy, íconos Yamis, cursor Bibata), tiling con Krohnkite.
  • Instalador: Calamares 3.4 (live USB con instalación gráfica), yay opcional para el AUR.
  • Sistema: NetworkManager, PipeWire, firewall ufw, zram, Snapper + grub-btrfs, drivers Intel, AMD y NVIDIA (abierto).
  • Lenguajes: GCC, Clang, CMake, Python (uv), Node.js, Bun, Deno, Java 21, Go, Rust.
  • Desarrollo: Code - OSS, Neovim, Helix, Git, GitHub CLI, Docker, Podman, distrobox, servidores de lenguaje (LSP).
  • Terminal: kitty, zsh + Starship, zellij, tmux, yazi, btop, fastfetch, ripgrep, fd, fzf.
  • Opcional al instalar (17 grupos): IA, móvil, ciencia de datos, DevOps, bases de datos, embebidos y más.

Compilación de la ISO

Nota sobre Systemback: Systemback solo funciona en distribuciones basadas en Debian/Ubuntu y no recibe mantenimiento desde 2016, por lo que no es compatible con Arch Linux. Para una base Arch, la herramienta equivalente (y oficial) es archiso, que cumple la misma función: generar una ISO en vivo e instalable a partir de un sistema configurado. Los pasos realizados fueron:
  1. Perfil base: se partió del perfil releng de archiso (el de la ISO oficial de Arch) y se adaptó como perfil propio (profile/).
  2. Lista de paquetes: se definieron los paquetes de la distribución en packages.x86_64 (escritorio, herramientas de desarrollo, drivers, instalador).
  3. Paquetes del AUR: los que no están en los repositorios oficiales (Calamares, temas, widgets, yay) se compilaron con aur/build.sh en un repositorio local de pacman.
  4. Personalización: la carpeta airootfs/ agrega la configuración que se copia al sistema (temas, fondos, zsh, kitty, Calamares, servicios). Los colores de todos los temas se generan desde una sola paleta con gen-themes.py.
  5. Construcción: sudo ./build.sh ejecuta mkarchiso, que instala los paquetes en un sistema raíz, lo comprime en SquashFS y genera la ISO arrancable en UEFI y BIOS (~5.2 GB).
  6. Pruebas: se probó en máquinas virtuales QEMU (./test.sh), en modo en vivo e instalado, y luego en hardware real desde una USB.
  7. Publicación: la ISO se subió a Google Drive con acceso público y el sitio web se publicó en Vercel.
